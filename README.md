# 🎵 Music Streaming Data Analysis & Dashboard
 ## Project Overview
 This project focuses on analyzing the Music Streaming Dataset to explore music genres, track popularity, artist performance, and audio features.
The project involves data cleaning using Python, data analysis using SQL, and interactive data visualization using Power BI to transform raw data into meaningful insights.

## Tools & Technologies
- Python: Pandas, NumPy
- SQL: PostgreSQL
- Power BI: Data Visualization and Dashboard Development
- 
  ##  Project Workflow
  1. Data Cleaning & Preprocessing – Python

Used Python to prepare the Music Streaming Dataset for analysis.
- Imported the dataset using Pandas.
- Examined dataset structure, data types, and data quality.
- Identified missing values and duplicate records.
- Removed unnecessary columns.
- Handled missing values in artist, album name, and track name columns.
- Loaded the cleaned data into PostgreSQL for further analysis.

- 2. Data Analysis – SQL

- Performed 10 analytical queries using PostgreSQL to explore music trends and track characteristics.
- Key Analytical Questions:
- Which music genres have the highest average popularity?
- What are the top 10 most popular tracks?
- Which artists have the highest average track popularity?
- Is danceability associated with popularity?
- Which music genres have the highest average energy?
- How does average track duration vary across music genres?
- Do explicit tracks have higher average popularity than non-explicit tracks?
- Which tracks have high energy but low danceability?
- Which genres have the highest average acousticness and instrumentalness?
- What are the top 3 most popular tracks within each genre?

- 3. Data Visualization – Power BI
Developed an interactive dashboard to present key music streaming insights.
Dashboard Features:
KPI Cards
- Total Tracks
- Unique Artists
- Average Popularity
- Unique Genres

Visualizations
- Top 5 Genres by Average Popularity
- Track Distribution by Musical Mode
- Top 5 Genres by Average Energy
- Track Details Table

Interactive Features
- Mode Category Slicer
- Track Genre Slicer
